**Zadanie 1**

W swoim środowisku programistycznym wygeneruj projekt **HelloGradle** wykorzystujący narzędzie Gradle. 
Projekt ma zawierać jedną klasę z metodą main wyświetlającą na konsoli HelloWorld. 
Po utworzeniu projektu spakuj go do pliku .jar, a następnie uruchom go z poziomu konsoli.

**Zadanie 2**

Utwórz projekt za pomocą narzędzia Gradle i swojego środowiska programistycznego.
Skonfiguruj plik build.gradle tak, aby w projekcie używana była Java w wersji 11.

Następnie dodaj pakiet Apache Commons Math (wskazówka: wyszukaj pakiet w https://mvnrepository.com/)

Korzystając z tego pakietu w Twojej klasie Compute zaimplementuj metodę wyliczającą dla serii zadanych liczb typu double
wartości statystyczne: średnią arytmetyczną, odchylenie standardowe, wariancję

Spakuj ten projektu do formatu .jar, a następnie wywołaj powyższą metodę w metodzie main z poziomu konsoli.

**Zadanie 3**

Przy pomocy narzędzia Spring Initializr utwórz projekt w Gradle, który
będzie miał następujące właściwości:
